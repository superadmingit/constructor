# Архитектура: платформа проектирования штампов листовой штамповки

Документ для программиста и для всех, кто подключается к проекту. Здесь решения и причины.
Как запускать код — в README.md.

## 1. Что строим и где границы

**Вход:** новая деталь (образец, чертёж или файл заказчика), материал, толщина, серия, прессы цеха.

**Выход:**
1. 3D и 2D-чертёж детали.
2. Развёртка (заготовка) в DXF.
3. Технологический процесс: операции, схемы штамповки, усилия, подходящие прессы.
4. Штампы по операциям: однооперационные, совмещённые (две операции за ход) или прогрессивный. Для каждого 3D, чертежи деталей штампа, спецификация и файлы для станков.

**Кто работает с платформой:**
- *Рабочий* даёт данные с телефона: фото, выбор картинкой, замеры по буквам. Он не проектирует.
- *Оператор* (наша сторона) собирает модель сложных деталей, которые не легли в шаблоны.
- *Конструктор* один раз утверждает нормы цеха (≈30 мин) и проверяет каждый штамп (≈10 мин).
- *Инструментальщик* изготавливает штамп по чертежам. *Наладчик* проводит пробу.

**Честные границы:**
- Версия 1 делает плоские детали и детали с гибами по прямым линиям: полки, в том числе переменной высоты, подсечки, отверстия и пазы. Не делает: коробки с угловой разгрузкой, вытяжку, рельефы и рёбра жёсткости, отбортовку по кривой. Такие детали программа сама отправляет конструктору.
- Без человека штамп в металл не идёт. Конструктор подписывает каждый штамп.
- Вырубной штамп делают только после пробной заготовки (см. раздел 2).
- Фото не даёт точности. Размеры берутся только из замеров или из чертежа/файла заказчика.

## 2. Где теряется точность и что с этим делает архитектура

| Источник ошибки | Масштаб | Защита |
|---|---|---|
| Замер не той поверхности, опечатка | мм и больше (пример: 26,6 вместо 14,4) | Картинка своей детали с буквой, проверка диапазона, «не знаю» вместо догадки, контрольные замеры, сверка габаритов 3D с замерами |
| Образец сам неточный (износ старого штампа, пружинение) | десятые мм | Брать чертёж заказчика, если есть. Иначе размеры утверждает заказчик |
| K-фактор (нейтральный слой) не тот для вашего металла | 0,5–1 мм на заготовке | Пробная заготовка до вырубного штампа. Таблица калибровки по материалу и толщине, пополняется после каждой пробы |
| Пружинение при гибке | градусы | Дожим (калибровка) в штампе, регулируемые элементы, проба |
| Ошибка в формуле или модели | любая | Одна модель для всех выходов. Тесты с ручным расчётом. Обратная проверка: развёртка, согнутая в модели, даёт замеренные размеры |
| Изготовление штампа на станках цеха | сотые мм | Конструкция под станки цеха. Пригонка пуансона по матрице. Покупные стандартные узлы. Электроэрозия на стороне для сложных окон |
| Решение программы неверно по опыту | — | Нормы утверждает конструктор, каждый штамп проверяет конструктор |

Пример, почему нужны тесты и обратная проверка: при переносе GEM0004 в общую модель нашлась ошибка в прежнем расчёте rev.E. Ступеньку там считали по нейтральному слою, а высоту ступеньки мерили по поверхностям. Независимый расчёт по реальным поверхностям даёт прибавку 0,997 мм, а не 1,494. Заготовка короче на 0,5 мм (148,14 вместо 148,64), отверстие Ø12 сдвигается на 0,5 мм. По rev.E ничего не резали, но вырубной штамп по ней вышел бы с ошибкой.

## 3. Главное решение: своё ядро на открытом CAD-ядре

| Вариант | Плюсы | Минусы |
|---|---|---|
| **A. Своё ядро на OpenCascade (CadQuery), Python** | Полная автоматизация без ручных шагов в CAD. Нет лицензий на рабочее место. Точность под нашим контролем и тестами. Одна модель → согласованные 3D, развёртка, чертёж, расчёт. STEP/DXF открывает любой CAD | Шаблоны штампов пишем сами |
| B. Onshape (облачный CAD, API) | Готовый листовой металл и развёртка, удобно смотреть в браузере | Зависимость от сервиса и подписки. Автоматические чертежи ограничены. Штампы всё равно писать самим |
| C. SolidWorks + Logopress / 3DQuickPress | Промышленное проектирование штампов, библиотеки узлов | Дорогие лицензии, Windows. Нужен обученный конструктор штампов: задачу «без конструктора» не решает |
| D. NX + Progressive Die Wizard | То же, что C | То же. От NX отказались раньше |
| E. Фото → CAD (Backflip, TechDraw AI) | Быстрый черновой контур по фото | Точности для штампов нет: сотые мм не получить. Гибы и толщину не понимают |

**Решение: A — ядро.** E можно подключить позже как помощника при вводе. B, C, D в ядро не входят: там конструктор открывает наши STEP и DXF, если ему удобнее в своём CAD.

Уже проверено в коде: OpenCascade строит корректные тела и STEP. Развёртки уголка и П-профиля совпадают с ручным расчётом до 0,001 мм. Габариты 3D GEM0004 совпали с замерами образца: 94,55 × 138,79.

## 4. Как деталь попадает в программу

1. **Файл заказчика — лучший вариант.** DXF развёртки загружается сразу. STEP разгибается: FreeCAD SheetMetal умеет разгибать и запускается без интерфейса. PDF или фото чертежа: ИИ читает размеры, человек подтверждает каждый.
2. **Только образец.** Фото → ИИ предлагает тип детали, число гибов и отверстий → рабочий подтверждает кнопкой → программа рисует *его* деталь с буквами A, B, C → рабочий мерит по одной букве на экран, с подсказкой «чем и как» → контрольные замеры → модель.
3. **Плоская деталь:** планшетный сканер → контур → DXF. Точность после калибровки проверим на пилоте.

**Правило:** ИИ никогда не даёт итоговых размеров. Он предлагает структуру детали и читает цифры с фото, а человек подтверждает. Геометрию считает только детерминированный код.

## 5. Единая модель детали (`stamp_engine/sheet`)

- Основание: контур в плане. На прямых рёбрах основания стоят полки: угол, направление, высота, участок ребра, переменная высота. Поперёк основания — подсечки. Отверстия и пазы есть в основании и в полках.
- Размеры записываются так, как их мерит рабочий: наружные размеры и габаритная высота полки. Пересчёт в развёртку делает программа: `OSSB = (r+S)·tg(θ/2)`, `BA = θ·(r+x·S)`, развёртка = наружные размеры − Σ(2·OSSB − BA).
- У каждого числа есть источник: измерено, со слов, допущение, нет данных. «Нет данных» никогда не превращается в «нормально».
- Из одной модели получаются развёртка (DXF), 3D (STEP), чертёж (PDF) и расчёт штампов, поэтому разойтись они не могут.
- **Шаблоны** (`families.py`): пластина, уголок, скоба (П-профиль), Z-профиль, дальше по вашим деталям. Это быстрый ввод для рабочих. Остальные детали оператор собирает в редакторе, в том же формате.
- Модель сама ловит ошибки описания: полка на кривом ребре, две полки в углу (коробка), полка налезает или прилегает к другой части детали, невозможная ступенька.

## 6. От детали к штампам

Цепочка: модель → проверки технологичности → операции → схемы → усилия → прессы → выбор схемы → штампы по шаблонам.

- Схемы: **A** совмещённый штамп и гибочные; **B** гильотина, обрубка с пробивкой, гибочные; **C** прогрессивный. Прогрессивный программа предлагает только там, где он разумен: небольшая деталь, гибы в одном направлении, серия окупает.
- Прессы: нет данных — «не подтверждено», а не «подходит».
- **Библиотека шаблонов штампов** (этапы 2–4):
  1. Пробивной и вырубной на блоке с направляющими колонками.
  2. Совмещённый: вырубка и пробивка за один ход.
  3. Обрубка по контуру, с пяткой против боковой силы.
  4. Гибочные: V, U с прижимом, Z (подсечка), L (полка с прижимом).
  5. Прогрессивный: раскрой полосы, позиции, пилоты, отрезка. Сначала только для малых простых деталей.
- Каждый шаблон выдаёт 3D сборки, чертежи деталей, спецификацию, DXF для ЧПУ и электроэрозии, заметки: сталь, твёрдость, посадки, пригонка.
- Правила конструкции зависят от станков цеха (раздел «Станки» страницы данных). Например, без электроэрозии внутренние углы окна матрицы не меньше радиуса фрезы, либо нужна вставка.
- Нормы цеха (`norms/shop_norms.yaml`) один раз утверждает конструктор. Таблица калибровки (K-фактор, пружинение) пополняется после каждой пробы, поэтому с каждым штампом программа точнее.

## 7. Статусы и безопасность

`ЧЕРНОВИК → ПРОВЕРЕНО ПРОГРАММОЙ → ПРОВЕРЕНО КОНСТРУКТОРОМ → ПРОБА → В ПРОИЗВОДСТВЕ`

Переходы не пропускаются, у каждого файла свой статус. Пока нормы не утверждены или развёртка не подтверждена пробой, все выходы помечены «ЧЕРНОВИК — НЕ ДЛЯ ИЗГОТОВЛЕНИЯ». Это закреплено тестами. После пробы наладчик заполняет короткую форму: размеры детали после штампа, что поправили. Эти данные идут в калибровку.

## 8. Платформа

| Часть | Решение | Почему |
|---|---|---|
| Экраны | Веб-приложение: телефон и компьютер, русский и узбекский | Ставить ничего не надо |
| Фронтенд | React (можно в Lovable). 3D-просмотр three.js (GLB), 2D — SVG | Знакомый вам стек |
| Данные, файлы, вход | Supabase (Postgres, хранилище, авторизация) | Знакомый вам стек |
| Геометрия | Отдельный сервис: Python, FastAPI, наше ядро, CadQuery/OpenCascade, ezdxf, Docker на VPS | OpenCascade — нативная библиотека и тяжёлые вычисления: в Edge Functions не работает |
| ИИ | Claude API с картинками: тип детали, чтение чертежа, показания штангенциркуля | Только подсказки, человек подтверждает |
| Связь | Telegram-бот: уведомления рабочим, листы проверки конструктору, ответы голосом | В цехах так уже общаются |
| Интеграции | STEP, DXF, PDF для NX, SolidWorks, Компаса, AutoCAD, Onshape. Позже модуль, который строит «родную» листовую модель в CAD конструктора из нашего JSON | Работает с любым CAD без лицензий |

## 9. Роли и экраны: простота для рабочего

**Рабочий, телефон — «Новая деталь»:**
1. Сфотографировать деталь по подсказкам: общий вид, сверху, сбоку, с торца, чертёж или бирка (уже работает, хранение 3 часа; постоянное хранилище и «ИИ читает фото» — этап 1).
2. «Что это за деталь?» — выбрать картинку. ИИ предлагает вариант, рабочий подтверждает.
3. Материал, толщина, серия — кнопками.
4. Замеры: одна буква на экран, на картинке *его* детали подсвечено, что мерить, ниже «как мерить», «не знаю», проверка опечаток.
5. Отверстия: нажать место на картинке и ввести размеры от краёв.
6. «Отправить». Дальше рабочий видит только статус: «ждём замер», «у конструктора», «штамп в работе», «проба».

**Оператор, компьютер:** редактор модели с 3D. Вопрос рабочему одной кнопкой: «перемерьте B».
**Конструктор:** Telegram и PDF: нормы один раз, лист проверки на штамп, ответ можно голосом.
**Инструментальный участок:** чертежи, файлы, отметка «изготовлено», форма пробы.

Принципы: одна мысль на экран, всегда картинка, никаких терминов без подсказки, крупные кнопки, «не знаю» — нормальный ответ, опечатки ловит программа.

| 2 | Шаблоны штампов: пробивка/вырубка, совмещённый, обрубка — 3D, чертежи, спецификация, DXF | 2–3 мес | 2–3 штампа изготовлены и прошли пробу не больше чем с одной доработкой |

## 11. Риски

- Детали цеха не ложатся в шаблоны → редактор оператора. Покрытие проверяем на 20–30 ваших реальных деталях до этапа 1.
- Ошибки замеров → проверки, контрольные замеры, фото показаний, сверка 3D.
- Конструктор недоступен → минимум его времени, оплата за лист, запасной проверяющий.
- Станки не держат точность → правила конструкции под станки, электроэрозия и закалка на стороне.
- Ответственность за штамп → статусы, подпись конструктора, обязательная проба.
